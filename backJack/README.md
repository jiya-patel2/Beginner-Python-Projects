# ♠️ Python Blackjack

> Beat the dealer. Test your luck. Don't go bust.

##  Overview
This is a classic **Blackjack** game built using Python. The goal is simple: beat the dealer's hand without going over 21.

I built this project to practice **Python control flow (loops/conditionals)**, **list manipulation**, and **game logic**. It simulates a real deck of cards using Python's `random` module.

**Key Features:**
* **Infinite Deck:** Cards are randomly generated and shuffled for every round.
* **Smart Ace Handling:** Automatically values Aces as 1 or 11 to give the player the best score.
* **Clean CLI Interface:** Easy-to-read text output with clear prompts.

## Technology Stack
* **Language:** Python 3.x
* **Modules:** `random` (for card shuffling), `os` (for clearing the screen).
* **Tools:** VS Code / Terminal.

## Installation & Setup

**1. Clone the repository**
```bash
git clone [https://github.com/jiya-patel2/Beginner-Python-Projects.git](https://github.com/jiya-patel2/Beginner-Python-Projects.git)
cd Beginner-Python-Projects/Blackjack
```

**2. Run the Game**
No external libraries are required.
```bash
python main.py 
```
